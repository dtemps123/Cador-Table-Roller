# Job boards, rumors, and adventure reference tables

Source: Campaign Handbook v0.4, pp. 16–25, 68–75, 77–101.

- Eight regional d20 job/rumor tables (160 authored entries, with updated PDF source-page references).
- Two composite any-marquisate tables and five initial/monthly count tables.
- `job-board-wayward-league.json`: eight staff commission ideas derived from their Handbook adventure hooks; not automatically posted.
- `wayward-league-introductory-scenarios.json`: twenty existing scenarios with concise descriptions and source references. An independent prep aid, not a required recruitment roll.

Run `python eccentric_east_job_and_rumor_gui.py`. The separate `job-and-rumor-records` library contains unposted templates and activated records. The reference tables are not modified when generating or saving logs. See the root README for activation, repeated postings, IDs, and regional cadence.
